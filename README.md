# Pulse Pro — Responsive Product Landing Page

A responsive product landing page for **Pulse Pro**, a fictional health companion app. It was built for the Web Development Week 02 minor project and showcases a professional single-page product experience.

## Features

- Responsive navigation bar with a mobile menu
- Hero section with product mockup and call-to-action buttons
- Four feature cards presented using CSS Grid
- Benefits section using responsive Grid and Flexbox layouts
- Customer testimonials
- Pricing call-to-action and contact footer
- Small CSS animations, hover effects, and a custom grid background

## Technologies used

- HTML5
- CSS3
- Tailwind CSS (CDN)
- JavaScript
- CSS Flexbox and Grid

## Run locally

Open `index.html` in a modern web browser. An internet connection is needed to load Tailwind CSS from the CDN.
